# Vibe Coding Framework

## English

Vibe Coding Framework is a Codex Skill for AI-assisted programming workflows. It helps an AI agent slow down before changing code, clarify vague product or feature requests, reduce them to first-principles facts, choose the smallest verifiable plan, and review whether the implementation solved the real problem.

Use it when a request involves vibe coding, unclear feature scope, product decisions that may lead to code, risky implementation changes, or post-change review. It is not meant for tiny explicit edits, formatting, or simple code explanations.

## 中文

Vibe Coding Framework 是一个服务于 AI 辅助编程的 Codex Skill。它的目标不是直接写代码，而是在改代码前、中、后帮助 Agent 建立稳定的判断框架：先澄清问题，再回到底层事实，最后选择最小、可验证的实现路径。

适合在 vibe coding、模糊功能需求、产品决策、用户留存/定价/ onboarding 判断、高风险改动、代码完成后复盘等场景中使用。不适合用于非常明确的小修改、格式化、简单代码解释等低风险任务。
